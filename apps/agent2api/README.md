# Agent2API

Agent2API 将多个 AI 编程客户端的登录态转换为 OpenAI 兼容 API，数据保存在本地 `/data`。

安装后请通过 1Panel 网站反向代理访问管理面板，将上游地址设为 `http://agent2api:3066`。首次访问时注册管理员账号，再到“网关 Key”页面创建 API Key。客户端的 API 地址为 `http://服务器地址:3065/v1`（端口可在安装时修改）。

管理面板与 API 网关使用不同端口；Compose 仅发布 API 端口，管理面板通过 `1panel-network` 内部访问。请勿将管理面板直接暴露到公网。

上游说明：本项目复用第三方 AI 客户端登录态，使用前请自行确认相关服务条款。上游标注仅供个人学习使用，不适用于商业用途。
