# Agent2API

Agent2API 将多个 AI 编程客户端的登录态转换为 OpenAI 兼容 API，数据保存在本地 `/data`。

安装后访问 `http://服务器地址:3066` 打开管理面板。首次访问时注册管理员账号，再到“网关 Key”页面创建 API Key。客户端的 API 地址为 `http://服务器地址:3065/v1`；面板端口和 API 端口均可在安装时修改。

管理面板与 API 网关分别使用 3066 和 3065 端口。若服务器端口对公网开放，请通过防火墙或反向代理限制管理面板访问。

上游说明：本项目复用第三方 AI 客户端登录态，使用前请自行确认相关服务条款。上游标注仅供个人学习使用，不适用于商业用途。
