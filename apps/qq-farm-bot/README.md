# QQ Farm Bot

QQ Farm Bot 是一个基于 Node.js 的 QQ 农场自动化工具，提供多账号管理、自动种植与收获、好友互动、活动管理、实时日志和 Web 控制面板。

## 使用说明

- 安装后通过 `http://服务器地址:端口` 访问面板，默认端口为 `3007`。
- 首次登录账号和密码均为 `admin`。登录后请立即在“设置 → 系统设置”中修改管理员密码；管理员密码不能通过环境变量设置。
- QQ 扫码登录依赖外部 `qq-miniapp-auth` 服务，本应用不会自动部署该服务。启用 QQ 扫码登录前，请先部署该服务，并在面板中配置可访问的 NapCat 接口地址和接口签名。
- 运行数据和日志持久化在应用目录的 `data/` 中，重建容器前请备份该目录。

## 构建说明

上游项目没有提供预构建 Docker 镜像。本应用提供两个安装版本：`20260928` 固定在提交 `864caf335192321c6a6c3737f4801f9b6a2b3a82`；`latest` 跟随上游 `master` 分支，并在安装时从当时的源码构建。首次安装需要访问 GitHub 和 npm 源，构建时间可能较长。

## 安全提示

管理面板包含账号、游戏配置和运行数据，请勿将管理端口直接暴露到公网。建议通过 1Panel 反向代理、VPN 或访问控制使用。
