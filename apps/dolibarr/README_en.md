# Dolibarr

Dolibarr is a self-hosted, open-source ERP & CRM suite covering customer relationship management, inventory, finance, project management, HR, invoicing, orders, and many more modules.

## Key Features

- 📋 Accounts, contacts, leads, opportunities, and sales pipeline management.
- 📦 Products, inventory, purchasing, and supplier management.
- 🧾 Quotes, orders, invoices, and payment management.
- 💰 Accounting, budgets, and bank reconciliation.
- 📅 Project management, tasks, and timesheets.
- 👥 Human resources and attendance.
- 📊 Custom reports and dashboards.
- 🧩 Rich module and extension ecosystem.

## 1Panel Deployment

1. Search for Dolibarr in the 1Panel app store and install.
2. Select an installed MySQL or MariaDB database service, then fill in the database name, database user/password, admin account/password, and site URL.
3. After installation, visit `http://SERVER_IP:PORT` to complete initial setup.
4. Data is persisted in the `data` directory.

> Tip: First install a MySQL or MariaDB service in 1Panel's "Databases" section, then select it from the dropdown when installing Dolibarr. 1Panel auto-creates the database and user.
