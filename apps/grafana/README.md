# Grafana

**Grafana** 是一个开源的可视化、监控与分析平台。它可以聚合来自 Prometheus、Loki、InfluxDB、MySQL、Zabbix 等数十种数据源的指标、日志和追踪数据，并通过丰富的仪表盘、告警和报表功能进行展示与分析。

**✨ 主要特点**：

1. **多数据源支持**：支持 Prometheus、Loki、InfluxDB、MySQL、PostgreSQL、Elasticsearch、Zabbix 等几十种数据源
2. **强大的可视化**：内置丰富的图表、仪表盘和表格组件，支持自定义面板与模板变量
3. **告警与通知**：支持基于规则的告警，并可通过钉钉、邮件、微信、Webhook 等发送通知
4. **灵活的认证**：内置用户与团队管理，支持 LDAP、OAuth、SAML 等 SSO 集成
5. **插件生态**：可通过官方与社区插件扩展更多数据源和应用功能
6. **Web 界面**：无需安装客户端，打开浏览器即可访问

**📖 使用说明**：

1. 安装完成后，通过您设置的端口访问 Grafana Web 界面
2. 使用安装时设置的管理员用户名和密码登录
3. 首次登录后可添加数据源、创建仪表盘或导入社区仪表盘模板

**🔒 安全提示**：

- 首次安装默认管理员账号为 `admin`，密码在安装时随机生成，请记得修改
- 建议通过 1Panel 反向代理为 Grafana 配置 HTTPS 访问
